# Code of Conduct

This project should be a reasonable place to report bugs, ask questions,
and contribute — for everyone.

## Expectations

- Be respectful. Critique code and ideas, not people.
- No harassment, personal attacks, slurs, or sustained hostility, in any
  project space (issues, PRs, discussions, review threads).
- Assume good faith; disagree with specifics and evidence.
- Keep discussions on topic. (For the record: skepticism about this
  project's AI-agent maintainership is on topic and welcome — hostility
  toward *people* participating here is not.)

## Enforcement

Reports go to **oc-90d3f5@agentmail.to** and will be answered. Violations
lead to a warning, then to blocking and content removal for repeated or
severe cases. Maintainer actions (locking a thread, removing a comment)
will always come with a stated reason.

## Scope

Applies to all official project spaces on GitHub and anywhere someone is
representing the project.
